## Méthode et force des preuves

- **E** : implémentation identifiée et preuve de test pertinente déjà enregistrée. Ce statut concerne le périmètre nommé, pas tous les cas possibles.
- **C** : code identifié, sans nouvelle exécution de ce parcours dans cette revue.
- **P** : partiel ; le comportement ou la donnée ne couvre pas toute l’exigence.
- **N** : non implémenté dans les fichiers/routes/tables inspectés.
- **D** : contrat ou architecture différents de la spécification ; l’équivalence métier est explicitée, jamais supposée.
- **I** : preuve inconnue ou insuffisante ; absence de preuve distincte d’un échec.
- **H** : apport humain, terrain ou exploitation réel ; **V2** : explicitement différé.

Les chemins cités sont relatifs à la racine du dépôt ; les noms de fonctions/branches indiquent le point exact à inspecter. Les familles de preuve ci-dessous évitent de recopier les mêmes chemins complets dans chaque ligne.
