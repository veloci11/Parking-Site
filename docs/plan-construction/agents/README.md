# Briefs des agents

18 rôles préparés, pas 18 agents de développement déjà ouverts. Chaque fichier est un brief prêt à transmettre avec une tâche précise, les fichiers autorisés, les versions de contrats et les critères de fin. La session permet au plus trois spécialistes et un coordinateur simultanés.

Voir le [plan de délégation](../10_EQUIPE_ET_DELEGATION.md) pour les vagues, verrous et l’attribution des 35 tâches. Le [registre vierge de missions](registre-missions.csv) sert à suivre les affectations réelles ; ses lignes sont au statut `prepare`, pas `en_cours`.

## Bloc à remplir avant envoi

```text
Mission concrète et résultat observable :
Tâche de backlog :
Version des contrats et tokens :
Fichiers exacts attribués :
Fichiers réservés à d’autres :
Entrées prêtes et dépendances validées :
Critères de fin :
Autorisations d’exécution et environnement :
Rapport au coordinateur : format du brief
```

Les rôles ne changent ni la charte, ni les données réelles, ni le périmètre commercial. Une nouvelle demande humaine est enregistrée par le coordinateur puis propagée aux agents concernés.
